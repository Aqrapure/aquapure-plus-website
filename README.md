# Aquapure Plus Vercel Website

A Vercel-ready Next.js website for Aquapure Plus Window Cleaning.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Deploy to Vercel

1. Create a free Vercel account.
2. Upload/import this project folder.
3. Deploy.
4. When your domain is ready, add `aquapure-plus.co.uk` in Vercel > Project > Settings > Domains.

## Contact form note

The form currently opens an email to `info@aquapure-plus.co.uk`. For a fully automated form submission on Vercel, connect a service such as Formspree, Basin, Resend, or a Vercel serverless API route.

## Google reviews note

The site includes a customer review section. Once you have the public Google Business Profile link, replace the placeholder note with your review link or an approved review widget.
